# barq — تطبيق حوالات أندرويد

نسخة أولية مستقلة من barq، بواجهة عربية واتجاه RTL.

## المزايا الحالية
- تسجيل حوالات محلية: إرسال واستلام.
- تسجيل بيانات حوالات Western Union وMoneyGram كعمليات داخلية.
- حفظ سجل العمليات محلياً على الجهاز.
- إنشاء إيصال داخلي لكل عملية.
- الطباعة عبر خدمة الطباعة في Android، بما فيها الطابعات الحرارية التي يدعمها نظام Android، أو الحفظ PDF.

## تنبيه مهم
هذا الإصدار لا ينفّذ تحويل الأموال فعلياً ولا يتصل بأنظمة Western Union أو MoneyGram. الإيصالات موسومة بأنها داخلية وغير رسمية ولا تثبت تنفيذ حوالة لدى أي شركة. يلزم تكامل رسمي مع مزود معتمد لتنفيذ التحويلات.

## بناء APK
GitHub Actions workflow: `.github/workflows/barq-android.yml`
المشروع: `barq-android/`
ناتج البناء: `app-debug.apk` داخل artifact باسم `barq-android-apk`.

البيانات تحفظ محلياً داخل WebView على الجهاز؛ احرص على تصدير/حفظ سجلاتك خارج الجهاز عند الحاجة، ولا تستخدم النسخة الأولية لحفظ بيانات حساسة أو كدفتر مالي نهائي.
